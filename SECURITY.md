# Security policy

Only the default branch is supported during prototype development.

Report vulnerabilities privately using GitHub private vulnerability reporting when enabled. If unavailable, contact the repository owner privately through an established channel. Do not put exploit details, secrets, financial records, or customer data in public issues.

No production integrations or external writes are implemented. All future filing and payment operations require explicit, version-bound approvals; payment approval is separate. See docs/security/THREAT-MODEL.md.

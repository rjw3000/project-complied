# Vercel visual preview

The Vercel project serves `public/index.html` as a **static synthetic visual preview** of the owner dashboard and upload → reconcile → review screens. It shares `public/styles.css` with the Python application shell and uses illustrative amounts from `fixtures/synthetic/`. Navigation, location scoping, requirement search/type filters, source detail panels and synthetic downloads work entirely in the browser. A review decision summary can be previewed but is never saved; uploads, recorded reviews, reminders and payments remain disabled. Do not enter real records here. This preview has no database, sessions, or Microsoft access.

`vercel.json` sets the static output directory to `public`. Vercel's Git integration deploys the merged main branch. The Vercel project currently has Vercel Authentication enabled; preserve that access policy. A green Vercel deployment means only that the static preview was published. It does not mean the Python app is hosted.

The authenticated Python application requires its persistent SQLite host, HTTPS, Entra registration, backup/restore checks and separately enabled reminder worker as documented in [Deployment](DEPLOYMENT.md). Its working import and review screens are available on the configured host, not on this static Vercel preview. Do not route the Python application's auth or data writes through a stateless Vercel function with ephemeral SQLite storage.

The expanded management screens cover overview, monthly upload/reconciliation/source review, requirements, a calendar with no verified deadlines, review queue, evidence library, integration setup and workspace policies. See [UI design and verification](UI-DESIGN.md). The calendar displays October 2026 without inventing dates. Location filtering changes displayed totals but never changes the full package scope.
